How a project runs

From first call to live product.

  1. 01 · Talk

    A short call

    What you're building, who it's for and when it needs to be live. You leave with a clear scope and a quote.

  2. 02 · Shape

    Plan & design

    Flows, screens and the data behind them — agreed before any real code is written, so nothing gets built twice.

  3. 03 · Build

    Deployed, fast and findable, with a proper handover — and I'm still a message away once it's live.
